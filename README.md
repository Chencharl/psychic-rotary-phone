# Mediation Analysis Framework for High-Dimensional Behavioral Data

This repository outlines the **statistical analysis pipeline** used in my thesis research conducted within the **All of Us Researcher Workbench**. It demonstrates the application of:

- Multiple imputation methods for mixed-type data with missingness
- High-dimensional causal mediation modeling using Partial Penalized Least Squares (PPLS)
- Bootstrap procedures to estimate confidence intervals
- Sensitivity analysis to test robustness against unmeasured confounding

**Note:** This repository does **not** contain any real participant data or output derived from the All of Us Research Program. All scripts use simulated variables or pseudocode for instructional purposes only.

For information about the data environment and research access, see [All of Us Research Hub](https://allofus.nih.gov/).
